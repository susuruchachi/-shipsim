▭ エリアライトをBlenderから取り込む
glTF規格はエリアライトに対応していないため、
Blenderのスクリプトで事前変換してから出力する方法が使えます。
📋 手順
① Blenderでエリアライトを含むシーンを開く
② Scriptingタブ → Newでテキストを作成
③ 下のスクリプトをコピーして貼り付け → ▶ Run Script
④ エリアライトが空(Empty)オブジェクトに自動変換される
⑤ File → Export → glTF 2.0 で出力
エクスポート設定: Include → Custom Properties ✓
(これがないと変換データが出力されません)
🐍 Blender Python スクリプト
⚠ 変換後の空オブジェクトは元のエリアライトと同じ位置・回転・サイズ・強度・色を持ちます。
スクリプトは元のエリアライトを削除せず、隣に空オブジェクトを生成します。
元のエリアライトはGLBに出力されないため、手動削除またはコレクションで非表示にしてください。

💡 照明の焼き込み（この端末の設定）
細かさ:
窓・灯具・エリアライト・煙突の照明・甲板灯が船を照らす明るさを、船ごとに一度だけ計算して端末に保存します。 全部の灯りが影付きで照らし（壁を抜けません）、毎フレームの計算はほとんど無くなります。
灯りを動かしたり明るさを変えたりすると、少し待ってから自動で焼き直します（数秒〜数十秒。その間は前の結果のまま）。 昼夜・明るさのスライダー・煙突照明のオン/オフは、焼き直さずにすぐ反映されます。
細かさを下げたときは、船を読み込み直すと反映されます。
🖼 テクスチャの最大サイズ（この端末の設定）
最大:
大きなテクスチャがたくさんあるモデルは、メモリが足りなくなって船体が真っ黒になることがあります。 「自動」では、モデルの中の画像の大きさを調べて、この端末に収まるように縮めて読み込みます （iPad・スマホは最大2048px、合計もおさえる）。読み込めなかった画像は、小さくしてやり直します。
変えたときは、モデルを読み込み直すと反映されます。
🎬 スクショと一緒に動画も保存（この端末の設定）
裏でずっと録画しているので、端末が温まりやすくなります。重いと感じたらOFFにしてください。

海面:
海面の重さはグラフィック品質とは別枠です。水面メッシュの細かさ・反射の更新頻度・流体シミュ(SWE)を調整します。動作が重い場合はここを下げてください。
